# iBrowser

متصفح سطح المكتب المتكامل ومفتوح المصدر من شركة [إديبي](https://idiibi.com).

![image](https://github.com/user-attachments/assets/6294ddd4-ff5a-41a2-be3c-6e15fc48042c)

**iBrowser 2.0** إعادة بناء كاملة للمتصفح: لوحة ذكاء اصطناعي جانبية تجمع
عدة مزودين، إعدادات متكاملة داخل التطبيق، ونظام إضافات/موديولات مفتوح
يستطيع أي مطوّر البناء عليه.

## أبرز ميزات الإصدار 2.0.0

- 🤖 **لوحة ذكاء اصطناعي جانبية** تعرض ChatGPT وClaude وGemini وCopilot
  وPerplexity وDeepSeek وGrok وPoe جنبًا إلى جنب مع الصفحة التي تتصفحها،
  مع إمكانية نسخ التحديد من الصفحة لاستخدامه في المحادثة.
- ⚙️ **إعدادات متكاملة داخل التطبيق** (عام، المظهر، الخصوصية، الذكاء
  الاصطناعي، الإضافات، حول) دون الحاجة لفتح نوافذ منفصلة.
- 🧩 **نظام إضافات/موديولات مفتوح المصدر** — أضف أزرارًا ووظائف جديدة عبر
  واجهة برمجية بسيطة، راجع [`PLUGINS.md`](PLUGINS.md).
- 🌗 **سمة داكنة/فاتحة** قابلة للتبديل، مبنية على هوية إديبي البصرية
  (التركواز `#038387` والكحلي الداكن `#0f172a`).
- 🔄 **نظام تحديثات حقيقي** يتحقق من [GitHub Releases](https://github.com/idiibigu/iBrowser-/releases)
  بدل المحاكاة العشوائية التي كانت في الإصدارات السابقة.
- 🔒 خصوصية أوضح: تفعيل/تعطيل إشارة Do Not Track، ومسح الكاش/الكوكيز/كل
  البيانات من مكان واحد.
- 📑 دعم التبويبات المتعددة، المفضلة، سجل التصفح، ووضع توفير البيانات (كما
  في الإصدارات السابقة).

## تثبيت التطبيق

### الطريقة 1: تثبيت التطبيق من ملف التثبيت
1. قم بتنزيل ملف `iBrowser-Setup-2.0.0.exe` من [صفحة الإصدارات](https://github.com/idiibigu/iBrowser-/releases)
2. قم بتشغيل ملف التثبيت واتبع التعليمات
3. سيتم إنشاء اختصار على سطح المكتب وفي قائمة ابدأ تلقائياً

### الطريقة 2: استخدام النسخة المحمولة
1. قم بتنزيل ملف `iBrowser-Portable-2.0.0.exe` من [صفحة الإصدارات](https://github.com/idiibigu/iBrowser-/releases)
2. قم بتشغيل الملف مباشرة بدون الحاجة للتثبيت

### الطريقة 3: تشغيل التطبيق من المصدر (للمطورين)
```bash
git clone https://github.com/idiibigu/iBrowser-.git
cd iBrowser-
npm install
npm start
```

## تطوير التطبيق

### المتطلبات
- Node.js (الإصدار 16 أو أحدث)
- npm (الإصدار 8 أو أحدث)

### الأوامر الأساسية
```bash
npm install     # تثبيت التبعيات
npm start       # تشغيل التطبيق في وضع التطوير
npm run dist    # بناء حزمة التثبيت
```

### بنية المشروع

```
src/
├── main.js                # العملية الرئيسية (نافذة، جلسة، IPC)
├── preload.js              # جسر contextBridge الآمن للنافذة الرئيسية
├── renderer.js              # منطق واجهة المتصفح (تبويبات، شريط عنوان...)
├── ui-ai-panel.js           # لوحة الذكاء الاصطناعي الجانبية
├── ui-settings.js           # واجهة الإعدادات المتكاملة
├── plugin-api.js            # واجهة برمجة الإضافات في الواجهة
├── core/
│   ├── settings.js          # مخزن الإعدادات الدائم (JSON)
│   ├── plugin-manager.js    # اكتشاف/تفعيل الإضافات
│   └── updater.js           # التحقق الحقيقي من التحديثات عبر GitHub
├── plugins/                 # الإضافات المدمجة (مثال: quick-notes)
├── pages/                   # صفحات مساعدة (حول، الأسئلة الشائعة...)
└── styles/                  # التنسيقات (بما فيها theme.css)
```

### نشر إصدار جديد
1. حدّث رقم الإصدار في `package.json`
2. حدّث `release-notes.md` بملاحظات الإصدار
3. أنشئ tag وادفعه إلى GitHub:
   ```bash
   git tag v2.0.0
   git push origin v2.0.0
   ```
   يقوم GitHub Actions تلقائيًا ببناء ونشر الإصدار (`.github/workflows/publish.yml`).

## نظام التحديثات

يتحقق iBrowser من أحدث إصدار منشور على GitHub Releases (`idiibigu/iBrowser-`)
عند الطلب من **الإعدادات > حول iBrowser > التحقق من التحديثات**، أو من
قائمة **مساعدة > التحقق من التحديثات**. عند توفر إصدار أحدث، يتم فتح صفحة
الإصدار في المتصفح الافتراضي لتنزيله يدويًا.
